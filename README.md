## 📌 About the Project

**LUMA** is a concept landing page for a product in **private beta**, designed around calm presentation, selective access, and launch readiness. The live page introduces it as “a calmer way to launch what’s next” and describes it as a digital experience for **thoughtful teams**, **curious creators**, and **beautifully ambitious ideas**. It invites users to join a waitlist and request access before the beta opens in **July 2026**. ([Live Demo](https://laurandreea10.github.io/LUMA/))

This project combines:

- 🌙 premium launch-page design  
- 📩 early-access waitlist flow  
- 🎨 style-switching exploration  
- 🧭 product storytelling  
- 🖥️ dashboard preview concepts
